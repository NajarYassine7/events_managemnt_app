# Events Management App

Web application for managing events, registrations and attendance (Laravel + MySQL).

## Team
- A: Users, auth, roles + Trello
- B: Events + report
- C: Locations, registrations + GitHub
- D: Attendance, statistics + Gantt, video

## Git rules
- Never push directly to `main`: use a branch and a pull request
- Branch names: `feature/<module>-<task>` (example: `feature/registrations-waitlist`)
- Commit style: `feat: ...`, `fix: ...`, `docs: ...`
- One other member reviews each pull request
- Run `git pull origin main` before starting work each day
- Small pull requests, merged often
